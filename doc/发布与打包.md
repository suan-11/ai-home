# 发布与打包

> 打包流程 + 版本记录。发布形态：**exe + pck 分离 + 外部 `assets/bgm/`**。
> 最近发布：**v0.1.0（2026-09-05，首个正式版）**。
> 相关：[开发文档](开发文档.md)（验证命令）、[正式角色计划](正式角色计划.md)（下一版前置）、[后续方向参考](后续方向参考.md)（发布善后）。

## 1. 发布形态

- `AIHome.exe`（引擎，约 109MB）+ `AIHome.pck`（资源包）**分离**：更新内容只需替换 pck
- 外部目录 `assets/`（与 exe 同级）：玩家 BGM 放 `assets/bgm/`；素材可直接替换（为 Mod 铺路）
- 玩家数据：`%APPDATA%\Godot\app_userdata\AIHome`（`config / memory / game / status / room_layout`），与运行器无关

## 2. 打包步骤

### 2.1 前置（一次性）

- 安装 Godot 导出模板：编辑器 `Editor → Manage Export Templates → Download and Install`（或手动放 `%APPDATA%\Godot\export_templates\4.7.2.stable\`）——本机已安装
- 导出配置：`export_presets.cfg`（Windows Desktop x86_64，`embed_pck=false`）

### 2.2 导出

```bash
# 项目根目录
"C:/Users/JOYCEPC/Godot/Godot_v4.7.2-stable_win64_console.exe" --headless --export-release "Windows Desktop" "D:\githb\ai-home\build\AIHome-win64\AIHome.exe" --path "D:\githb\ai-home"
```

### 2.3 压缩

```bash
cd build
zip -r AIHome-win64.zip AIHome-win64     # 或直接压缩 AIHome-win64 文件夹
```

产物结构：

```
build/
 AIHome.pck               # 资源包（调试用）
 AIHome-win64/
     AIHome.exe           # 引擎（约 109MB）
     AIHome.pck           # 游戏资源包
     assets/bgm/          # 玩家自备 BGM（放 wav/ogg/mp3/flac）
```

## 6. 注意事项

- BGM 扫描顺序：发布版 `assets/bgm/`（exe 同级）→ 开发版 `res://assets/bgm` → `user://bgm` 兜底；`assets/bgm` 导出时排除出 pck
- API Key 由玩家在「设置 → AI 设置」自填；仓库与打包产物不含 Key
- 导出前建议检查：应用图标（`project.godot` 的 `config/windows_native_icon` / `export_presets.cfg` 的 `application/icon`，需 `.ico`，当前为空）；版本与版权字段已设置（2026-09-13：`0.1.0` / `Copyright (c) 2026 suan-11`）
