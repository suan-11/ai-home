## 2. 当前完成状态（P0 / P1 / P2 已完成，P3 首项 Graphwar 已实现，2026-08-30）

### 基础（早期阶段）
- 温馨小屋房间（墙体/地板/家具装饰）、网格 A* 寻路、家具碰撞、窗口自适应 / F11
- 角色：char_03 梅尔（左侧原图立绘 + 128×128 像素小人 0.25 缩放；`assets/chars/README.md` 为资源规范）
- 电脑 = 虚拟操作系统（ScreenArea 内不叠加；`Transition.*` + `show_desktop/open_game_select/open_gomoku/open_chat/open_diary/go_back/get_current_screen_id`）
- 游戏选择 + 15×15 AI 五子棋（胜 +3 / 平 +1 / 负 0）
- 聊天应用（OpenAI 兼容，`AIConnector.send_chat`）、日记应用（按日期自动整理；有 API 走 AI，失败降级规则）
- 记忆系统（`user://memory.json`：short_term 40 条 + long_term_summary ≤500 字 + key_facts ≤20 条）
- 好感度系统（`user://game.json`：0-100 默认 50；聊天 AI 判定 +1 每日上限 10）
- 房间布置（布置台 `decorate`：长按拾起/点击放下/恢复默认，存 `user://room_layout.json`；该交互不加好感）
- 新手攻略（首次进入自动弹，`general.guide_seen`）+ 右侧「家具介绍」（读 `FURNITURE_SPECS.desc`）

### P0 手机消息
- 入口：主界面「设置」图标下方手机图标（设置/手机均为图标按钮）
- `scenes/ui/phone_overlay.tscn` + `scripts/ui/phone_overlay.gd`：半透明竖屏单页聊天窗（不遮房间）；复用 `AIConnector.request_json` 返回 `{reply, emotion, action, affection, reason, mood_delta}`
- 消息节奏：发送 → `RECEIVE_DELAY=1.0s` → 提示音（`assets/sfx/notify.wav`）+ 头顶「！」（`notify_fx`）+ 顶部横幅（`notification_toast`）→ `REPLY_DELAY=0.8s` → AI 回复
- 系统提示不插入聊天流：手机右上角 `HintLabel` 逐条队列（滑入/停留 `HINT_DURATION=1.1s`/淡出）
- 角色反馈：气泡（`bubble.tscn`，36 字截断）+ `char_controller.play_action`（wave/hop/sad）
- 消息同样计入记忆/日记/好感度；AI 动作指令（家具交互 = 寻路后自动触发）

### P1 吸引移动
- 点击地板/家具 = 「引导」：点击处放置吸引物（`ATTRACT_ITEMS` 6 种：爱心/小鱼干/苹果/星星/毛线球/书卷；`general.attract_item` 默认 random，设置「通用」可固定或随机），物品上下漂浮后角色被吸引
- 反应：停顿 + 头顶「！」+ hop 小跳 → `ATTRACT_AFTER_DELAY=0.4s` → 自愿寻路；到达后物品消失
- 走神：好感度 <50 时 75% / ≥50 时 90% / ≥70 时 100% 响应；未响应时头顶「？」（与「！」同款特效，停留更久）
- 家具点击到达后自动触发交互（一次点击）
- 已移除原目标十字标记与寻路路径线（`_draw_target` / `_draw_path`）

### P2 自主行为 + 状态系统（初版）
- `scripts/autoload/StatusManager.gd`（新 autoload，`user://status.json`）：饱食/心情/疲惫 0-100（初始 70/60/30）内部 float 平滑变化；食物状态 `none|raw|cooked`；自主好感当日计数（每日上限 +3）；`last_seen` 时间戳
- 现实时间：在线缓慢变化（饱食 -1/30min、疲惫 +1/30min）；测试倍率 `general.dev_state_speed`（×1/×5/×10，设置→通用，**测试用，正式版移除**）
- 行为调度（`GameMain._autonomy_*`）：空闲 ≥8s 且电脑 OS/全屏浮层未开时开始（手机开着照常）；玩家任何输入打断；状态阈值优先（饿→吃 / 累→睡·沙发 / 心情低→窗边）→ 随机闲逛 → 现实钟点日程（22–6 倾向休息）；同目标冷却
- 进食链路（新家具）：冰箱 `fridge`（拿食物）→ 直接吃（生食 +20 饱食、+3 疲惫）或 厨具 `cook`（做饭，心情+1）→ 饭桌 `eat` 或 沙发 `rest` 吃（熟食 +35 饱食、+2 心情、+2 疲惫）；无食物时提示先拿
- 自主用电脑：走到电脑旁不弹 OS，电脑旁出现「一起玩」按钮（`UI/PlayTogetherButton`），点击 `open_panel()+open_game_select()` 直达游戏选择
- 自主好感：正式自主行为完成 50% 概率 +1，日上限 +3；自主行为写日记（`MemoryManager.record_daily_event(..., "autonomy", ...)`）
- 离线结算：上线时离线 ≥ `1800 / dev_state_speed` 秒 → 先按时间算自然变化，再 AI（带人设/记忆/状态摘要）输出 `{"satiety","fatigue","mood","affection","message"}` 一次性应用（±钳制）；`message` 显示为角色气泡并写日记；affection 计入每日 +3；失败自动降级为时间计算
- 聊天：`MemoryManager.build_chat_context` 注入好感度描述；手机/电脑判定支持 `mood_delta`（-2~+3 缺省 +1）经 `StatusManager.apply_delta` 应用
- 状态感知：纯表现（行为 + 偶尔气泡），无任何数值 UI

### P3 Graphwar 仿·函数对打（已实现，2026-08-30）
- `scenes/ui/graphwar_game.tscn` + `scripts/ui/graphwar_game.gd`：回合制函数对打，玩家 vs AI；**直接输入函数表达式**（LineEdit + 内置解析器），炮弹从**自己出发点**沿「y = 出发高度 + f(x) − f(0)」飞行（曲线相对出发点，起点固定在自己身上；x = 离开出发点的水平距离）；命中对方位置 +1，先得 3 分获胜
- 坐标平面 -10..10 × -5..5；每轮双方出发点 y 各自随机 -3..3（玩家左侧蓝菱形、AI 右侧红圆）；**发射前不显示预览/辅助线**，只有发射后显示轨迹
- 表达式支持：+ - * / ^ ( )、数字、x、pi、sin/cos/tan/abs/sqrt/ln，乘号可省略（0.5x）；无效公式在状态栏提示
- 界面内附「教程」按钮（规则/示例/语法说明）
- AI：65% 概率解析瞄准发射（直线/抛物线/绝对值/三次/顶点式/三角函数解析反解），其余 35% 随机出招
- 胜负沿用通用规则：胜 +3 / 平 +1 / 负 0；记录 `MemoryManager.record_daily_event(..., "graphwar", ...)`
- 已接入游戏选择界面（`game_select` → `computer_panel.open_graphwar`）
- 已知简化：无 AI 难度档/障碍物，后续可加；「8 张预设函数卡+滑杆」方案已按用户反馈废弃
