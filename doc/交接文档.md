## 4. 文件地图（关键）

### 主流程
- `scenes/main.tscn`：房间 / 角色 / 立绘 / 侧边栏按钮
- `scripts/GameMain.gd`：房间绘制、家具、布置、吸引、自主行为、离线结算、浮层接线（主流程，约 1600 行）

### 全局单例（`project.godot` → autoload）
- `GameManager`（好感等级 / 互动次数 / 当前角色，`user://game.json`）
- `ConfigManager`（`user://config.json`）、`MemoryManager`（记忆 / 日记，`user://memory.json`）
- `AIConnector`（OpenAI 兼容 + JSON 容错）、`StatusManager`（`user://status.json`）、`AudioManager`（BGM）

### 角色
- `assets/chars/<char_id>/`：`persona.json` / `portrait.png` / `sprites/` / `portraits/` / `interactions.json` / `anim_map.json`
- `scripts/logic/character_catalog.gd`（发现 / 可用判定 / 显示名 / 立绘路径）、`scripts/logic/character_interactions.gd`（互动加载）
- 切换链路：`GameManager.set_current_char_id()` → `current_char_changed` → `GameMain._apply_character`
- 默认角色常量：`GameManager` / `StatusManager` / `char_controller` 的 `DEFAULT_CHAR_ID`（当前 `"char_03"`）

### 电脑 OS / 游戏
- `scripts/ui/computer_panel.gd`（屏幕导航 API）、`desktop_screen`、`game_select`（`GAMES` 注册表）
- 游戏：`gomoku_game` / `graphwar_game` / `tictactoe_game` / `blackjack_game` / `snake_game`（各 `.tscn` + `.gd`）
- 新增游戏必须接线 4 处：注册表 → `open_xxx` → `screen.<game>_requested` → `go_back()`（教训见 §7）

### P0 / P1 / UI
- `phone_overlay`（手机窗 + HintLabel 队列）、`bubble`、`notify_fx`、`notification_toast`
- 吸引移动 / 自主行为逻辑在 `GameMain.gd`（`_attract_*` / `_autonomy_*`）
- UI 主题：`theme/ui_theme.tres` + `scripts/ui/ui_constants.gd` / `common_title_bar.gd` / `common_status_bar.gd`
- 历史 UI 方案与对照稿：`archive/UI重绘方案.md`、`archive/ui-mockups/`

### 家具
- `GameMain.FURNITURE_SPECS`（唯一数据源：id / name / interaction / desc / size / pos / color）

## 7. 约定与教训（速查）

- **文档原则**：README 面向展示（人话）；需求 / 计划 / 参考进 `doc/`；历史文档进 `archive/`
- **需求流程**：用户口述 → 助手记录并追问 → 确认后写入对应文档
- **AIConnector**：错误回调经 `bind` 会先收到 message 参数导致错位，用 lambda 包装；`_extract_json` 去围栏 + 括号配对；失败打印原文；prompt 用严格 JSON + 示例；`affection` / `mood_delta` 多形式归一化
- **新增游戏漏接线**曾导致按钮无反应（`snake_requested`，2026-09-04 已修）——按 4 处清单检查
- **冒烟前挪开 `user://config.json`**（防真实 API 调用）
- **GDScript 坑**：`var x := 动态值` 报 Cannot infer the type；`%` 格式化优先级高于 `+`（多段拼接加括号）；`Array[String]` 无 `join()`；`--headless --script` 无 Autoload
- 用户中文交流，偏好温馨暖色系；「似人非人」的二次元角色感
- **文档批量修改**：用脚本批量替换时不要用短模式；PowerShell 单元素嵌套数组必须逗号包装（,@(...)），否则会被展平、取到字符串首字符当替换对。2026-09-12 曾因此把开发文档全文 c→o 后重写；改完用关键词计数校验。
