# AIHome 交接文档

> 这是给下一个对话/开发者接手用的文档。目标是以最快速度了解项目现状、约定和下一步。

## 1. 项目概览

- 名称：AIHome / AI-Character-home
- 引擎：Godot 4.7.2（GDScript）
- 平台：PC（当前 Windows 开发，Godot 项目本身跨平台）
- 类型：像素风桌面陪伴 + AI 对话 + 小游戏
- 仓库：Git 仓库，工作区当前干净

## 2. 当前完成状态

### 已实现
- 温馨小屋房间（墙体/地板/家具装饰）
- 网格 A* 寻路，家具碰撞
- 家具交互：走到旁边触发交互（预留接口）
- 角色：char_03 梅尔
  - 左侧立绘：原图 525×1043 直接叠加，按比例缩放贴屏幕左边缘
  - 像素小人：128×128 直接像素化原图，运行时 0.25 缩放
  - 资源规范：`assets/chars/README.md`
- 电脑 = 虚拟操作系统
  - 仿电脑界面（外框/桌面/标题栏/任务栏）
  - 子界面在同一 `ScreenArea` 内切换，禁止叠加
  - 屏幕切换 API：`show_desktop / open_game_select / open_gomoku / open_settings / open_chat / go_back / get_current_screen_id`
  - 预设动画：`Transition.FADE / SLIDE_LEFT / SLIDE_RIGHT / SLIDE_UP / SLIDE_DOWN / SCALE`
  - 导航栈：桌面 → 应用 → 返回
- 游戏中心
  - 游戏选择界面
  - 标准 15×15 AI 五子棋（结果面板/重开/退出/胜负钩子）
- 设置应用
  - 入口：游戏主界面右上角“设置”（主界面浮层，不进电脑）
  - 标签页：通用 / 显示 / 音频 / AI 设置
  - 保存到 `user://config.json`
- 聊天应用
  - 入口：桌面“聊天”
  - 消息区 + 输入框 + 发送
  - 自动加载梅尔 `persona.json` 的 system prompt
  - 通过 `AIConnector.send_chat()` 调用 OpenAI 兼容接口
  - 对话自动记录到记忆；重开聊天自动带上下文
- 记忆系统（MemoryManager）
  - 聊天历史持久化：近期 40 条 + 按日期归档到 `user://memory.json`
  - 长期摘要（≤500 字）+ key_facts（AI 提炼；无 API/失败时降级规则拼接）
  - 日记按日期存储，由日记应用自动整理
- 好感度系统（GameManager）
  - 0-100，默认 50；每日记录变化原因到 `user://game.json`
  - 聊天：AI 按人设判定本轮是否 +1，每日上限 10
  - 五子棋：胜 +3 / 平 +1 / 负 0
  - 家具互动：每种每天首次 +1（电脑桌除外）
- 日记应用（电脑内）
  - 按日期浏览，打开当天空档自动整理
  - 有 API 时 AI 按人设撰写；无 API/失败时规则拼接
- 窗口自适应 / F11 全屏

### 未完成 / 已知问题
- 聊天好感度判定与日记/记忆 AI 提炼需要真实 API Key；无 API 时降级为规则（历史仍在记录）
- 立绘差分表情 / 多角色切换：未做
- 角色状态数值与权重寻路：用户确认“以后再说”
- 聊天未真实验证过网络请求（需要真实 API Key 测试）
- API Key 目前明文存 `user://config.json`，未加密（后续可接入系统 Keychain 或加密）
- 无流式输出（stream）
- 多方向行走动画（上下左右）未做
- BGM/音效、TTS、房间编辑器、多房间、Mod、导出打包均未做

## 5. 配置说明

- 设置保存位置：`user://config.json`（Godot 用户数据目录，不在仓库内）
- 记忆/日记保存位置：`user://memory.json`（MemoryManager）
- 好感度保存位置：`user://game.json`（GameManager）
- AI 配置字段：`api_base` / `api_key` / `model` / `max_tokens` / `temperature`
- 默认 Base URL：`https://api.deepseek.com/v1`
- 注意：API Key 不要提交到仓库

## 6. 添加新应用步骤（电脑 OS）

1. 新建 `scenes/ui/xxx_screen.tscn`，根 Control 填满 `ScreenArea`
2. 新建 `scripts/ui/xxx_screen.gd`，需要返回时 emit `back_requested`
3. 在 `scripts/ui/computer_panel.gd`：
   - 加 `SCREEN_XXX` 常量与 `open_xxx()`
   - 在 `_setup_screen_signals()` 连接
   - 需要时在桌面/游戏选择界面加入口按钮并发出信号
