## 2. 为什么还没有独立 .exe

Godot 独立导出（`--export-release`）需要**导出模板**（platform export templates）：
- Windows 模板包约 **500MB**（`Godot_v4.7.2-stable_export_templates.tpz`）；
- 当前开发沙箱无外网，无法代下；装好模板后一条命令即可导出。

## 3. 正式打包步骤（5 分钟）

### 3.1 安装导出模板（一次性，本机有网即可）

方式 A（推荐，图形界面）：
1. 打开 Godot 编辑器 → 菜单 `Editor` → `Manage Export Templates…` → `Download and Install`；
2. 等待下载完成（也可先下载 `Godot_v4.7.2-stable_export_templates.tpz` 再 `Install from File`）。

方式 B（命令行）：下载 `.tpz` 后解压到 `%APPDATA%\Godot\export_templates\4.7.2.stable\`。

### 3.2 导出

```bash
# 项目根目录（D:\githb\ai-home）
"C:\Users\JOYCEPC\Godot\Godot_v4.7.2-stable_win64_console.exe" \
  --headless --export-release "Windows Desktop" \
  "D:\githb\ai-home\build\AIHome-win64\AIHome.exe" --path "D:\githb\ai-home"
```

- 产物：`build/AIHome-win64/AIHome.exe`（已内嵌 pck，**单个文件即可运行**，无需安装 Godot）。
- 如需更小体积：`export_presets.cfg` 中 `embed_pck` 改为 false，产物为 `AIHome.exe + AIHome.pck` 两个文件一起分发。

### 3.3 分发 / GitHub Release

```bash
cd build
zip -r AIHome-win64.zip AIHome-win64   # 或直接压缩 AIHome-win64 文件夹
```

在 GitHub Releases 新建 `v0.1.0-alpha（或 v0.1.0）`，上传：
- `AIHome-win64.zip`（Windows 玩家下载即玩：解压 → 双击 AIHome.exe）
- 可选附加 README.txt（玩法简介 / 设置 API Key 位置 / 免责声明：内置 API Key 需玩家自填才能聊天）

## 4. 打包产物结构（示意）

```
AIHome-win64/
├── AIHome.exe            # 可执行文件（约 60-80MB，含引擎；内嵌 pck）
└── （如关闭 embed_pck 则多一个 AIHome.pck）
```

```
build/
├── AIHome.pck            # 资源包（预览用 / debug 用）
└── AIHome-win64/         # 正式导出产物（模板装好后生成）
```

## 5. 注意事项

- `user://` 数据（config/memory/game/status/room_layout）存在 `%APPDATA%\Godot\app_userdata\AIHome`，与运行器无关，打包后玩家首次运行自动创建。
- API Key 由玩家在「设置 → AI 设置」中自填；仓库与打包产物均不含 Key。
- 发布前建议：换正式应用图标（`project.godot` 的 `config/icon` 与 exe `application/icon`）、写版权信息与玩法说明。
