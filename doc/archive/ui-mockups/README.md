# UI 重绘方案 · 预览稿

## 怎么看

用浏览器直接打开 **`preview.html`**（双击即可，无需服务器 / 构建）。

页面从上到下依次是 4 套方案（A 暖屋手账 / B 现代清爽 / C 夜幕霓虹 / D 像素玩具箱），
每套都渲染了同一组界面内容：主房间 UI、电脑 OS 桌面、游戏中心、手机消息、聊天应用，
方便并排对比「配色、描边、圆角、阴影、排版」的差异。

> 预览是**静态 HTML 风格稿**，不是 Godot 运行截图；
> 最终视觉以 `theme.tres` + StyleBoxFlat 实现，色值与组件规则见 `../UI重绘方案.md`。

## 与现有计划的关系

- 实现顺序仍以 [`doc/UI重构与重绘计划.md`](../UI重构与重绘计划.md) 的批次为准（主题底座 → 通用组件 → 游戏中心数据驱动 → 逐个 App 重绘 → 回归验收）。
- 本目录只承担「方向选择题」的视觉展示；用户选定后，把结论（token 表、组件规格）回写到 UI 重构计划文档。
