# AIHome UI 重绘方案（4 套待选）

> 记录时间：2026-09-05
> 状态：**方案 A（暖屋手账）已选定**（2026-09-05 用户确认）；下一步 = 按 `doc/UI重构与重绘计划.md` 批次 0 开始实现主题底座与通用组件。
> 可视化预览：`doc/ui-mockups/preview.html`（浏览器直接打开，同一组界面用 4 种风格对照渲染）。

---

## 0. 设计前提（所有方案共同遵守）

- 基准画布 **480×360**，全屏走 `canvas_items` 拉伸；所有界面改为**锚点 + 容器 + 主题常量**，不再新增手写绝对坐标。
- 不破坏既有接线：`computer_panel` 的 `open_* / go_back`、各屏 `back_requested / finished / restarted` 信号、多角色动态显示名、手机与电脑 OS 共存规则。
- 视觉必须服务产品定位：**温馨、陪伴、生活气息**，角色「似人非人」的二次元感；房间是共同生活空间，任何浮层都不能把房间完全挡住。
- 所有方案都先落**全局 `theme.tres` + 通用组件**（标题栏 / 状态栏 / 卡片按钮列表 / 结果弹窗 / 滚动条 / 气泡），风格只体现在主题常量上，切换风格不重写节点树。

## 1. 方案总览

| 维度 | 方案 A：暖屋手账 | 方案 B：现代清爽 | 方案 C：夜幕霓虹 | 方案 D：像素玩具箱 |
|---|---|---|---|---|
| 关键词 | 温馨·治愈·手账·木屋 | 干净·高效·扁平·留白 | 深色·玻璃·霓虹·睡前 | 8-bit·复古掌机·玩具箱 |
| 情绪 | 松软、被陪伴 | 清爽、易用 | 沉浸、科技感 | 好玩、复古 |
| 与像素房间契合度 | ★★★★★ | ★★☆ | ★★☆ | ★★★★★ |
| 480×360 小屏可读性 | ★★★★ | ★★★★★ | ★★★ | ★★★ |
| 开发成本 | 中 | 低 | 中高 | 中（需像素字体/九宫格素材） |
| 需要新素材 | 少量（纸张/木纹纹理可选） | 几乎无 | 中等（发光、玻璃需 shader 或双层 StyleBox） | 中等（像素字体、像素图标、9-patch） |
| 主要风险 | 手账装饰过度会显乱 | 与房间像素风割裂 | 霓虹易脏、夜间高对比刺眼 | 中文像素字体难找，可读性下降 |
| 一句话 | 把「暖屋」做得更精致 | 把「界面」做得更好读 | 把「陪伴」做到深夜 | 把「像素」做得更纯粹 |

## 2. 方案 A：暖屋手账风（推荐默认方向）

延续现有暖色像素基础，向「精致手账 / 温馨小木屋」方向打磨：奶白纸面卡片 + 木纹深底 + 暖金/蜜桃强调色，圆角与细描边统一，电脑屏做成复古米色 CRT 壳。

### 2.1 色彩 Token

| Token | 色值 | 用途 |
|---|---|---|
| `bg_room` | `#2A211E` | 房间外围 / 最深底色 |
| `wall` | `#EDD9B8` | 墙面 |
| `floor` | `#B98A5E` | 地板 |
| `surface` | `#FBF3E4` | 主面板（纸面白） |
| `surface_2` | `#F2E3CB` | 次级面板 / 悬停 |
| `border` | `#D9B98C` | 描边（暖金） |
| `accent` | `#E8A87C` | 主强调（蜜桃橙） |
| `accent_2` | `#7F9F6A` | 次强调（温柔绿） |
| `text` | `#4A3B33` | 正文 |
| `text_dim` | `#8A7466` | 次要文本 |
| `danger` | `#C96B5A` | 关闭 / 失败 |
| `overlay` | `rgba(30,24,22,0.78)` | 浮层半透明底 |

### 2.2 组件规则

- 面板：圆角 10px、1.5px 暖金描边、可选 NoiseTexture 纸纹（很淡，10% 透明度）。
- 按钮：奶白填充 + 浅阴影；悬停微升（offset y −2 + 阴影加深）；按下贴回纸面（无偏移、阴影更浅）。
- 标题栏：木纹深棕条 + 居中浅色标题 + 右侧圆角关闭钮。
- 气泡：奶白圆角 + 底部小三角尾巴；手机气泡玩家侧蜜桃橙、角色侧纸面白。
- 电脑 OS：米色 CRT 外框（外圈深棕、内圈米白、屏幕区墨绿黑），任务栏「开始」做木头圆钮。
- 滚动条：暖金细轨 + 纸色圆头。

### 2.3 布局要点

- 主界面右侧边栏：4 个**方形纸片图标钮**（设置 / 手机 / 角色 / 家具介绍），图标线性暖金。
- 状态栏（左上）改为圆角便签条，斜贴 2° 更像手账贴纸。
- 游戏中心：卡片式列表，每个游戏一张「游戏卡」（图标 + 名称 + 一句话简介 + 难度点），滚动列表保留。
- 角色立绘左下角姓名牌做成木质挂牌。

## 3. 方案 B：现代清爽扁平

把「电脑 OS」部分向现代轻量桌面（类 macOS / 轻 Web OS）靠拢：白 + 浅灰 + 清透蓝绿，卡片无描边、靠阴影分层，强调最优先的「可读性」。

### 3.1 色彩 Token

| Token | 色值 | 用途 |
|---|---|---|
| `bg_room` | `#F4F5F7` | 房间外围（极浅灰） |
| `wall` | `#E8F0F5` | 墙面（淡蓝白） |
| `floor` | `#DDE7EC` | 地板（浅木灰） |
| `surface` | `#FFFFFF` | 主面板 |
| `surface_2` | `#F1F4F8` | 次级面板 / 悬停 |
| `border` | `#E2E7EE` | 细分隔线 |
| `accent` | `#5CA9A7` | 主强调（清透蓝绿） |
| `accent_2` | `#F2A05D` | 次强调（珊瑚橙） |
| `text` | `#2B2D33` | 正文 |
| `text_dim` | `#7A828E` | 次要文本 |
| `overlay` | `rgba(43,45,51,0.35)` | 浮层遮罩 |

### 3.2 组件规则

- 面板：圆角 12px、无描边，阴影 `0 2px 10px rgba(43,45,51,0.08)`。
- 按钮：主色实心（白字）或灰底（深字）；无立体感，按下变深 8%。
- 标题栏：白底 + 底部 1px 分隔线，标题左对齐小号加粗。
- 电脑 OS：顶部磨砂半透明窗口条 + 桌面大图标 2×2 网格 + 底部 Dock 式任务栏。
- 滚动条：4px 圆头、浅色轨道，几乎隐形。
- 气泡：圆角 14px，手机聊天气泡对齐左右分布。

### 3.3 布局要点

- 主界面侧边栏收窄为**竖排线性图标**（无外框，仅鼠标悬停出现浅灰底），节省横向空间，房间视野更大。
- 状态栏改为顶部**细胶囊**，不挡画面。
- 游戏中心：2 列游戏卡片网格（大图标 + 名称），一屏 4~6 个，更多则滚动。
- 立绘左下角姓名为**半透明小胶囊**，弱化存在感。

## 4. 方案 C：夜幕霓虹

面向「深夜陪伴」场景的沉浸方案：深紫黑底 + 玻璃拟态 + 电紫/青霓虹微光，让 AI 小屋像一盏深夜亮着的灯。适合后续做成「夜间模式」与方案 A 并存。

### 4.1 色彩 Token

| Token | 色值 | 用途 |
|---|---|---|
| `bg_room` | `#0F0D16` | 房间外围（深紫黑） |
| `wall` | `#161226` | 墙面 |
| `floor` | `#1D1830` | 地板 |
| `surface` | `rgba(34,29,54,0.72)` | 主面板（玻璃） |
| `surface_2` | `#2A2445` | 次级面板 |
| `border` | `rgba(124,107,255,0.35)` | 霓虹描边 |
| `accent` | `#A476FF` | 主强调（电紫） |
| `accent_2` | `#5EE7E0` | 次强调（荧光青） |
| `text` | `#EDE8FA` | 正文 |
| `text_dim` | `#9A93B8` | 次要文本 |
| `overlay` | `rgba(10,8,18,0.6)` | 浮层遮罩 |

### 4.2 组件规则

- 面板：圆角 14px、半透明深底、1px 霓虹描边 + 轻微外发光（Godot 可用两层 StyleBox 模拟，或 Panel 内加 Gradient 边缘）。
- 按钮：深紫填充 + 青色描边；主按钮紫→青渐变（可用 StyleBoxFlat 渐变或贴图）。
- 标题栏：呼吸感霓虹细线（顶部 1px 渐变条），标题居中小号。
- 电脑 OS：星夜桌面 + 壁纸感渐变背景；任务栏底部半透明玻璃条。
- 气泡：深紫玻璃 + 霓虹描边，文字浅紫白。
- 扫描线/微光动画（可选 shader，性能注意 480×360 下不要全屏高频）。

### 4.3 布局要点

- 主界面侧边栏图标改为**发光线性图标**，悬停青焰色。
- 状态栏改为左上角微光呼吸点 + 文字，弱化面板感。
- 手机小窗玻璃效果最明显（半透明可透出房间），与「房间不能被完全挡住」诉求天然契合。
- 适合夜间模式：设置里「主题：日间（方案 A）/ 夜间（方案 C）」。

## 5. 方案 D：像素玩具箱

把「像素」推到极致：8-bit 高饱和 + 粗黑描边 + 硬阴影 + 掌机/玩具箱质感，与房间的像素小人、像素家具完全同源，游戏中心会非常出彩。

### 5.1 色彩 Token

| Token | 色值 | 用途 |
|---|---|---|
| `bg_room` | `#1D2A3A` | 房间外围（深海军蓝） |
| `wall` | `#33475E` | 墙面 |
| `floor` | `#2B3B4F` | 地板 |
| `surface` | `#3A4E68` | 主面板（藏蓝） |
| `surface_2` | `#2E4258` | 次级面板 |
| `border` | `#FFD34E` | 描边（亮黄，3px 粗边） |
| `accent` | `#FFD34E` | 主强调（亮黄） |
| `accent_2` | `#FF9F45` | 次强调（活力橙） |
| `text` | `#F5F0E6` | 正文 |
| `text_dim` | `#A8B4C6` | 次要文本 |
| `overlay` | `rgba(16,24,36,0.82)` | 浮层遮罩 |

### 5.2 组件规则

- 面板：`box-shadow 4px 4px 0 #14202E` 硬投影 + 3px 亮黄/白描边，圆角 4px 以内（近直角）。
- 按钮：亮黄底黑字或橙底白字；按下整体**向右下位移 2px、硬投影消失**（"物理按下"）。
- 标题栏：上白下黑双条或高对比色带 + 按钮像素箭头。
- 字体：等宽像素字体（需引入中文像素字体资源，如「Zpix / 像素中文」授权字体；未就绪前用粗体无衬线 + letter-spacing 替代并降低字号）。
- 电脑 OS：CRT 屏（圆角小、扫描线可做 2~3px 暗线 overlay）+ 掌机式边框。
- 气泡：白底黑描边直角气泡 + 像素「！」号。

### 5.3 布局要点

- 主界面侧边栏做成「工具箱」：4 个像素图标钉在右侧，图标 16×16 风格。
- 状态栏做成像素横幅，右下角小血条式状态点。
- 游戏中心：每个游戏一张「卡带」样式卡片（像游戏卡带插槽），选中的卡带弹起。
- 缺点：中文像素字体字库、版权需要确认；文字多的大段落（教程/日记）可读性下降，建议长文本仍用清晰无衬线。

## 6. 推荐组合与落地路径

### 6.1 推荐：A 为主基调 + D 点缀 + C 预留夜间模式

- **主体采用方案 A**：与产品定位（温馨陪伴、暖色像素）最匹配，风险最低，改造量可控。
- **游戏中心 / 游戏内**吸收方案 D 的「卡带、硬投影、物理按下」细节，强化"一起玩"的乐趣感。
- **方案 C** 作为后续「夜间模式」预留（主题系统做成可切换时自然支持，本期不做）。
- **方案 B** 的阴影分层、分隔线、滚动条细节可作为通用组件的「结构标准」，避免 A 手账风做成"贴纸乱糊"。

### 6.2 实施批次（与 UI重构与重绘计划.md §3 对齐）

1. **批次 0 · 主题底座**：`theme.tres`（依据选定的 2.x 表格 token 建立）、字号层级、通用 StyleBox（面板/按钮/滚动条/气泡）、基准布局常量；先跑通「电脑 OS 外壳 100% 填 ScreenArea」。
2. **批次 1 · 通用组件**：`CommonTitleBar / CommonStatusBar / ResultPanel / ScrollButtonList / CommonCard`，替换 5 个游戏屏与聊天/日记里的重复写法。
3. **批次 2 · 游戏中心数据驱动**：`games` 注册表（id/name/desc/icon/scene）→ 自动生成卡片列表（A 风格纸卡 + D 风格卡带可选皮肤）。
4. **批次 3 · 逐个重绘**：桌面 → 游戏屏 → 聊天/日记 → 设置 → 手机 → 帮助/布置 → 角色选择 → 主界面侧边栏。
5. **批次 4 · 打磨回归**：悬停/按下/禁用态、tooltip、滚动反馈；480×360 与全屏双分辨率检查；多角色、好感结算、手机通知链路回归。

### 6.3 每次提交的验收清单

- [ ] `Godot --headless --import --path .` 无报错
- [ ] `Godot --headless --path . --quit-after 5` 无 Parse Error
- [ ] 界面内文字/头像仍动态取自 `CharacterCatalog`（无「梅尔」硬编码回退）
- [ ] 打开/返回按钮信号链与 `computer_panel` 保持一致
- [ ] 手机小窗打开时房间仍可见，电脑 OS / 全屏浮层打开时入口禁用规则不变
