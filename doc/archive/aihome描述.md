### **项目名称：AI-Character-home**

- **平台：** PC端 (Windows)
- **视觉风格：** 左侧二次元立绘差分 + 右侧4方向像素风场景
- **核心玩法：** 桌面陪伴 + **智能权重寻路** + AI对话
- **商业模式：** 纯粹为爱发电 (Free)

---

### **一、 产品界面与交互设计**

#### **1. 界面布局 (UI Layout)**

- **左侧：二次元立绘展示区**
    - **内容：** 高清二次元风格静态立绘。
    - **动态表现：** 通过切换**差分表情**（开心、惊讶、害羞、生气、睡眠）反馈情绪。
    - **功能：** 点击触发语音或特定表情，作为情感反馈的核心窗口。
- **右侧/背景：像素互动区**
    - **内容：** 像素风格房间场景（卧室/书房）。
    - **角色：** 4方向行走的Q版像素小人。
    - **网格系统：** 整个房间划分为不可见网格，支持寻路。

#### **2. 核心交互逻辑**

- **智能权重寻路 (Smart Weighted Grid Movement)：**
    - **基础机制：** 摒弃平滑移动，采用经典“走格子”方式。
    - **动态权重系统：** 每个格子都有隐藏的“吸引力权重”，根据以下维度实时变化：
        - **时间：** 晚上床的权重变高，白天书桌/电脑旁权重变高。
        - **状态：** 饿了增加冰箱/餐桌权重，困了增加床权重。
        - **用户行为（新增）：** 如果用户长时间（如3分钟）没操作鼠标/键盘，角色会触发“无聊/想念”状态，大幅增加走到屏幕边缘或电脑前的权重，主动“找你玩”。
    - **指令移动：** 用户点击家具，角色自动计算路径，一格一格走到目标位置并执行动作。
- **视线跟随：** 像素小人的脸/眼睛会实时跟随鼠标位置转动。

### **二、 技术架构方案**

#### **1. 前端开发**

- **引擎推荐：** **Godot Engine** (首选)。
    - *理由：* 对2D像素游戏支持极佳，节点系统适合“立绘+小人”混合布局，导出PC端体积小，适合“为爱发电”项目传播。
- **UI框架：** 使用引擎自带UI系统实现左侧立绘区和右侧场景区的分离。

#### **2. AI 对接模块**

- **协议标准：** OpenAI API 兼容协议。
- **配置逻辑：**
    - 用户在设置页输入 `Base URL` 和 `API Key`。
    - **自动获取模型名：** 程序启动或保存配置时，调用 `/v1/models` 接口，解析返回的 JSON 数据，自动填充模型名称下拉框。
- **本地存储：** 用户的 API Key 加密存储在本地（如使用 Windows DPAPI 或简单的异或加密），绝不上传服务器。

### **三、 美术资源规划 (自绘)**

1. **左侧立绘 (二次元 + 差分)：**
    - **基础体：** 画一套标准站姿/坐姿的基础线稿和上色。
    - **差分部件：** 将眼睛、嘴巴、眉毛单独分层绘制。
        - *表情库：* 开心、难过、惊讶、困惑、睡眠（闭眼）。
        - *口型同步：* 简单做3个口型（闭嘴、微张、大张）配合TTS音量跳动。
2. **右侧像素小人 (4方向)：**
    - **尺寸：** 建议 32x32 或 64x64 像素。
    - **动作帧：**
        - *待机：* 2-4帧呼吸动画。
        - *行走：* 4帧循环（上、下、左、右四个方向）。
        - *交互：* 坐下、睡觉、看书等特定动作各2-3帧。
3. **场景素材：**
    - 绘制一套通用的像素家具素材包（床、桌、椅、电脑、窗户）。
    - 背景图层与前景交互层分离，方便后续扩展新房间。

### **四、 开发路线图 (Roadmap)**

#### **阶段一：原型验证 (Prototype)**

- 搭建 Godot 基础工程。
- 实现左侧立绘显示 + 点击切换表情功能。
- 实现右侧网格地图 + 像素小人移动（先做无权重随机移动）。
- 跑通 OpenAI API 对话流程（硬编码测试）。

#### **阶段二：核心功能完善**

- 接入权重寻路算法（根据时间/状态/用户行为改变格子权重）。
- 实现 API 配置页 + 自动获取模型名功能。
- 绘制第一套完整的立绘差分（至少5种表情）和像素小人4方向动作。
- 实现鼠标跟随视线功能。

#### **阶段三：内容填充与优化**

- 绘制家具素材，搭建第一个完整房间场景。
- 增加物品交互逻辑（点击家具触发特定动作）。
- 优化 TTS 语音合成（如果有）。
- 打包发布 v0.1 版本到爱发电/网盘。
