## AIHome v0.1.0 — 温馨小屋 · 与 AI 一起生活 🏠✨

一个让 AI 住在像素房间里、像宠物主人一样陪伴它的桌面小游戏。
它有自己的生活：会闲逛、会用家具、会累会饿有心情；也会回应你的吸引、
陪你玩小游戏、接你的手机消息——**自主，但可被影响**。

### 🎮 玩法亮点

- **温馨像素房间**：点击地板/家具 = 吸引**梅尔**过去（不是命令，它会自己决定跟不跟你走 😉）
- **仿电脑操作系统**：桌面里有游戏、聊天、日记；五个小游戏都能和 AI 对战：
  - 五子棋 / Graphwar 函数对打 / 井字棋 / 21点 / 贪吃蛇（胜 +3 好感、平 +1）
- **手机消息**：随时给角色发消息；它会收到提示音、头顶「！」、气泡回复，还会按指令走向家具
- **好感等级系统**：从「朋友」到「家人」（Lv1~Lv6，EXP 累积），升级有横幅 + 专属台词；
  等级越高越亲近、越愿意回应你
- **自主生活（P2）**：饿了找吃的、累了去休息、无聊玩电脑；离线再上线还有「想念」留言
- **角色互动**：摸摸头 / 投喂零食 / 玩小玩具 / 一起看书 / 浇花，台词与效果数据驱动
- **立绘差分**：6 种表情随心情和事件切换（开心/低落/害羞/走神/惊讶…）
- **多角色**：主界面「角色」图标可切换（梅尔 / 小灯〔临时占位〕），每人好感/记忆/日记独立
- **UI 重绘（方案 A 暖屋手账）**：奶油纸面卡片 + 木纹电脑外壳 + 蜜桃暖金点缀
- **自备 BGM**：在游戏目录 `assets/bgm/` 放入 `.wav/.ogg/.mp3/.flac` 即可循环播放

### 🚀 运行方式（Windows）

1. 下载 `AIHome-win64.zip`，解压
2. 双击 `AIHome.exe`（单文件，无需安装 Godot）
3. 想用 **AI 聊天 / 手机消息 / 日记 AI 整理**：先到 **设置 → AI 设置** 填入 Base URL 与 API Key
   （OpenAI 兼容接口，如 DeepSeek）；不填也能玩小游戏和房间互动
4. 数据自动保存在本地：`%APPDATA%\Godot\app_userdata\AIHome`

### ⚠️ 说明与已知限制

- 小灯为**临时占位角色**（仅基础素材），后续会替换为正式角色
- 状态参数/互动数值为初版，后续随实测微调
- 无 API Key 时：聊天/手机 AI 回复、离线 AI 结算、日记 AI 整理不可用（自动降级）
- 发布包未内置 BGM；示例生成器见仓库 `tools/gen_bgm.py`
