AIHome UI 重绘方案 · 视觉对照稿

同一组界面（主房间 UI / 电脑桌面 / 游戏中心 / 手机消息），按 4 种风格分别渲染，用于方向选择。
预览为静态 HTML 风格稿，非 Godot 运行截图；最终实现 = 全局 theme.tres + StyleBoxFlat，色值与组件规则见 doc/UI重绘方案.md。

A 暖屋手账（推荐） B 现代清爽 C 夜幕霓虹 D 像素玩具箱

方案 A · 暖屋手账风 推荐默认方向 · 温馨治愈

延续现有暖色像素魂，向「精致手账 / 小木屋」打磨：奶白纸面卡片、木纹深底、暖金描边、蜜桃橙强调；电脑做成复古米色 CRT 壳。最贴合「温馨陪伴」的产品定位。
