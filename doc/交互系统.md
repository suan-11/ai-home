# 交互系统说明

## 通用规则

点击任意家具时：

1. 如果角色当前格子是这件家具的“旁边一格”（四方向相邻），直接触发交互。
2. 如果角色不在旁边，则自动寻路到离角色最近的空位。
3. 到达空位后不会自动触发交互，需要再点一次家具。

交互通过角色控制器的预留接口统一发出：

```gdscript
signal interaction_triggered(interaction_name: String)

func trigger_interaction(interaction_name: String) -> void:
    _path.clear()
    _state_machine.change_state(CharacterStateMachine.State.IDLE)
    _sprite.play("idle")
    interaction_triggered.emit(interaction_name)
```

## 当前家具与接口名

| 家具 | 接口名 | 说明 |
|---|---|---|
| 床 | `sleep` | 睡觉（预留） |
| 电脑 | `computer` | 打开电脑四宫格面板 |
| 书架 | `read` | 阅读（预留） |
| 椅子 | `sit` | 坐下（预留） |
| 电视柜 | `watch` | 看电视（预留） |
| 沙发 | `rest` | 休息（预留） |
| 落地灯 | `light` | 开灯/阅读（预留） |
| 盆栽 | `water` | 浇水（预留） |

## 电脑面板

当触发 `computer` 交互时，主场景会打开 `scenes/ui/computer_panel.tscn`。

面板结构：

- 屏幕中央半透明遮罩 + 居中 Panel
- 四宫格：
  - 左上：游戏（AI 五子棋）
  - 右上：聊天
  - 左下：日记
  - 右下：空位
- 底部状态文字
- 右上角关闭按钮

打开动画：淡入 + 从 0.85 缩放回 1.0。
关闭动画：淡出。

### 五子棋游戏

点击“游戏”会打开 `scenes/ui/gomoku_game.tscn`。

- 9×9 棋盘
- 玩家执黑，AI 执白
- AI 使用启发式评分选择落点
- 支持重新开始和返回电脑面板

### 扩展电脑功能

在 `scripts/ui/computer_panel.gd` 中：

- 给对应 Button 添加 `pressed` 回调。
- 需要打开新界面时，在当前面板之上实例化新的 Control 场景。
- 聊天模块统一调用 `AIConnector.send_chat(messages)`，该接口已预留。
