# 交互系统说明

## 界面布局

- 左侧：角色立绘叠加层（直接叠图、贴屏幕左边缘，不移动房间位置）
- 右侧/中央：像素房间、角色移动与交互
- 电脑系统界面：居中弹出的仿操作系统窗口

## 通用规则

点击任意家具时：

1. 如果角色当前格子是这件家具的“旁边一格”（四方向相邻），直接触发交互。
2. 如果角色不在旁边，则自动寻路到离角色最近的空位。
3. 到达空位后不会自动触发交互，需要再点一次家具。

交互通过角色控制器的预留接口统一发出：

```gdscript
signal interaction_triggered(interaction_name: String)

func trigger_interaction(interaction_name: String) -> void:
    _path.clear()
    _state_machine.change_state(CharacterStateMachine.State.IDLE)
    _sprite.play("idle")
    interaction_triggered.emit(interaction_name)
```

## 电脑面板

当触发 `computer` 交互时，主场景会打开 `scenes/ui/computer_panel.tscn`。

面板为仿电脑系统界面：显示器外框、桌面底色、标题栏、任务栏、电源灯等装饰。

面板结构：

- 屏幕中央半透明遮罩 + 居中 Panel
- 四宫格：
  - 左上：游戏（先进入游戏选择界面）
  - 右上：聊天
  - 左下：日记
  - 右下：空位
- 底部状态文字
- 右上角关闭按钮

打开动画：淡入 + 从 0.85 缩放回 1.0。
关闭动画：淡出。

### 电脑系统屏幕切换 API

电脑面板是一个“操作系统外壳”，所有子界面都在同一个屏幕区域内切换，不会叠加。

切换动画预设：

| 常量 | 动画 |
|---|---|
| `Transition.FADE` | 淡入淡出 |
| `Transition.SLIDE_LEFT` | 从左滑入，旧界面滑出 |
| `Transition.SLIDE_RIGHT` | 从右滑入（返回方向） |
| `Transition.SLIDE_UP` | 从下滑入 |
| `Transition.SLIDE_DOWN` | 从上滑入 |
| `Transition.SCALE` | 缩放淡入 |

软件（子界面/新游戏）可调用的 API：

```gdscript
# 打开桌面
computer.show_desktop(Transition.FADE)

# 打开游戏选择
computer.open_game_select(Transition.SLIDE_LEFT)

# 打开五子棋
computer.open_gomoku(Transition.SLIDE_LEFT)

# 返回上一层
computer.go_back(Transition.SLIDE_RIGHT)

# 查询当前界面
computer.get_current_screen_id()
```

### 游戏选择界面

点击“游戏”会打开 `scenes/ui/game_select.tscn`，先选择具体小游戏。

当前包含：
- 五子棋
- 更多游戏（待添加）

后续新增游戏时，在游戏选择界面添加按钮即可。

### 五子棋

选择“五子棋”后打开 `scenes/ui/gomoku_game.tscn`。

- 标准 15×15 棋盘
- 玩家执黑，AI 执白
- AI 使用启发式评分选择落点
- 游戏结束显示结果面板：再来一局 / 退出
- 预留接口：
  - `game_finished(result)`：游戏结束信号
  - `_on_game_won()` / `_on_game_lost()` / `_on_draw()`：胜利/失败/平局处理钩子
  - `game_restarted` / `game_exited`：重开/退出信号

### 扩展电脑功能

在 `scripts/ui/computer_panel.gd` 中：

- 给对应 Button 添加 `pressed` 回调。
- 需要打开新界面时，在当前面板之上实例化新的 Control 场景。
- 聊天模块统一调用 `AIConnector.send_chat(messages)`，该接口已预留。

## 设置应用

- 入口：游戏主界面右上角“设置”
- 界面：顶部 4 个标签页，下方切换对应子界面
  - 通用：主人称呼、自动保存
  - 显示：像素缩放、显示 FPS、启动全屏
  - 音频：背景音乐/音效音量、静音
  - AI 设置：Base URL、API Key、模型、Max tokens、温度
- 保存后写入 `ConfigManager`（`user://config.json`）

## 聊天应用

- 入口：电脑桌面“聊天”
- 界面：消息区 + 输入框 + 发送/返回
- 自动加载 `assets/chars/char_03/persona.json` 的 `system_prompt`
- 请求通过 `AIConnector.send_chat()` 调用 OpenAI 兼容 `/chat/completions`
- 设置里未填 API 时会提示“请先配置 API”

## 房间布置（布置台）

- 入口：点击房间里的「布置台」（家具 `decorate`）
- 交互规则：角色走到布置台旁边后点击触发，弹出全屏布置界面
- 操作：
  1. 在网格里**长按家具 0.4 秒** → 拾起（出现半透明鬼影跟随鼠标）
  2. 移动鼠标到目标格子，**点击** → 放下
  3. 出界或与其他家具重叠时不能放下（红色边框提示）
- 按钮：
  - 恢复默认：一键还原内置默认布局（未保存前可在界面内继续调整）
  - 保存并应用：写入 `user://room_layout.json` 并立即应用到房间
  - 关闭：不保存退出
- **该交互不加好感度**（与 sleep/read 等家具交互不同）
- 配置格式：`{"objects": [{"type": "bed", "pos": [10, 1]}, ...]}`
