# 开发文档

## 技术栈

- 引擎：Godot 4.x
- 语言：GDScript
- 渲染：GL Compatibility
- 项目配置：`project.godot`

## 核心模块

### 角色资源
- 当前初始角色：`char_03`（梅尔）
- 角色目录规范：`assets/chars/README.md`
- 立绘：`assets/chars/char_03/portrait.png`（原图原尺寸，按比例缩放显示）
- 像素帧：`assets/chars/char_03/sprites/`（128×128 源图，直接像素化原图，运行时 0.25 缩放）
- 人设：`assets/chars/char_03/persona.json`

### 主场景 `scenes/main.tscn`
- 根节点：`Main`（Node2D）
- 子节点：
  - `Room/Character`：角色
  - `UI/StatusLabel`：状态提示
  - `UI/PortraitLayer`：左侧角色立绘叠加层（直接叠图、贴左边缘，鼠标穿透，不影响房间点击）
  - `UI/SettingsButton`、`UI/PhoneButton`、`UI/FurnitureButton`：主界面右上角「设置」「手机」「家具介绍」（设置/手机为图标按钮）
  - 运行时动态加入 `UI/ComputerPanel`、`UI/SettingsOverlay`、`UI/LayoutOverlay`、`UI/HelpOverlay`、`UI/PhoneOverlay`、`UI/Bubble`（全屏浮层/手机小窗/气泡）

### 角色控制 `scripts/char/char_controller.gd`
- 网格逐格移动
- A* 寻路（`scripts/logic/pathfinding.gd`）
- 状态机（`scripts/logic/state_machine.gd`）
- 家具碰撞
- 交互触发信号

### 寻路 `scripts/logic/pathfinding.gd`
- 4 方向 A*
- 支持障碍格
- 返回 `Array[Vector2i]` 形式的路径

### 电脑系统（OS 外壳）与游戏模块
- `scenes/ui/computer_panel.tscn`：电脑操作系统外壳（显示器/桌面/任务栏 + 屏幕容器）
- `scenes/ui/desktop_screen.tscn`：桌面屏幕（游戏/聊天/日记图标）
- `scenes/ui/game_select.tscn`：游戏选择界面
- `scenes/ui/gomoku_game.tscn`：标准 15×15 五子棋界面
- `scripts/ui/computer_panel.gd`：OS 外壳，屏幕切换动画 API（FADE/SLIDE/SCALE）、导航栈
- `scripts/ui/computer_screen.gd`：仿电脑界面装饰绘制（外框/桌面/标题栏/任务栏）
- `scripts/ui/desktop_screen.gd`：桌面图标与模块请求信号
- `scripts/ui/game_select.gd`：游戏选择，发出 `gomoku_requested` / `back_requested`
- `scripts/ui/gomoku_game.gd`：15×15 棋盘、玩家/AI 落子、胜负判断、AI 启发式评分、结果面板与预留接口

### 如何在电脑系统中加新应用
1. 创建 `scenes/ui/xxx_screen.tscn`，根节点为 Control（填充屏幕区域）。
2. 在 `scripts/ui/computer_panel.gd` 中 preload 该场景，并增加 `open_xxx()` / `Transition` 调用。
3. 在桌面场景或游戏选择界面增加入口按钮，发出对应请求信号。
4. 在 `computer_panel.gd` 的 `_setup_screen_signals()` 中接线，并使用 `_open_screen()` / `go_back()` 导航。

### 配置与 AI
- `ConfigManager`：读写 `user://config.json`（通用/显示/音频/AI 设置；`general.guide_seen` 记录新手攻略是否已看）
- `MemoryManager`：记忆/日记（`user://memory.json`）
- `GameManager`：好感度（`user://game.json`）
- `AIConnector`：`send_chat(messages)` 调用 OpenAI 兼容 `/chat/completions`；另有 `request_json` / `request_text`（带每请求回调），信号：`chat_reply` / `text_reply` / `json_reply` / `error_occurred`
- 设置界面：`scenes/ui/settings_screen.tscn` + `scripts/ui/settings_screen.gd`（标签页切换）
- 主界面设置浮层：`scenes/ui/main_settings_overlay.tscn` + `scripts/ui/main_settings_overlay.gd`（主界面右上角入口）
- 聊天界面：`scenes/ui/chat_screen.tscn` + `scripts/ui/chat_screen.gd`（消息区 + 输入 + API 调用 + 记忆/好感判定）

### 手机消息（P0，已实现）
- 入口：主界面侧边栏「设置」图标下方手机图标（`UI/PhoneButton`，图标 `assets/ui/icon_phone.svg`；设置按钮同步改图标）
- 手机小窗：`scenes/ui/phone_overlay.tscn` + `scripts/ui/phone_overlay.gd`——半透明竖屏单页聊天窗（右侧，不遮住房间）；根节点鼠标穿透，可点击面板输入；消息复用 `MemoryManager`（记忆/日记）与 `GameManager`（好感度）
- 消息链路：发送后先延迟（`RECEIVE_DELAY=1.0s`）模拟“角色收到”，触发 `notification_triggered`（提示音 + 头顶「！」特效 + 顶部通知横幅），再停顿（`REPLY_DELAY=0.8s`）后调 `AIConnector.request_json` 让 AI 返回结构化 JSON：
  ```json
  {"reply":"回复内容","emotion":"happy|normal|surprised|sad","action":"wave|hop|sad|none|sleep|read|sit|watch|rest|light|water|computer","affection":true,"reason":"理由"}
  ```
- 系统提示：不再插入聊天流，改为手机右上角逐条队列显示（`HintLabel` + `_enqueue_hint`：滑入 → 停留 `HINT_DURATION=1.1s` → 淡出），如“已发送，等待查看…”“梅尔收到了消息！”“正在输入…”“好感 +1 …”
- JSON 容错：`AIConnector._extract_json` 支持去掉 Markdown 代码围栏、跳过字符串引号做括号配对提取最外层 JSON；失败时打印 AI 返回原文到控制台，并提示“已记录到控制台”
- 电脑聊天同步加固：好感判定提示词改为严格 JSON + 示例；`chat_screen._parse_affection` 兼容 bool/数值/字符串（true/yes/是/1/对/加分），判定失败时显示「好感判定未完成，本轮跳过」（不阻塞后续对话）
  `action` 中 8 个家具交互会在 GameMain 中寻路到家具旁并触发 `trigger_interaction`（到达后自动触发）
- 反馈：消息提示音 `assets/sfx/notify.wav`（`GameMain._play_notify_sound`）+ 角色上方气泡 `scenes/ui/bubble.tscn`（`bubble.gd`，36 字截断）+ 角色动作动画 `char_controller.play_action`（wave/hop/sad 轻量 Tween）
- 收到消息特效：`scenes/ui/notify_fx.tscn`（头顶「！」弹出/弹跳/淡出）+ 顶部通知横幅 `scenes/ui/notification_toast.tscn`（手机图标 + “梅尔 收到了新消息”）
- 手机与电脑 OS 共存规则：入口仅主界面侧边栏；电脑 OS / 全屏浮层打开时不可开（`GameMain._on_phone_pressed` 判断）

### 吸引移动（P1，已实现）
- 点击地板/家具统一走 `GameMain._attract_to_cell` / `_attract_to_furniture`：先 `character.stop_movement()`，头顶「！」特效（复用 `notify_fx`）+ `play_action("hop")`，停顿 `ATTRACT_AFTER_DELAY=0.4s` 后自愿寻路
- 响应概率：`_will_respond()` 按好感度 ≥70→100% / ≥50→90% / 其余→75%；不走时冒「？」气泡（复用 `bubble`）且本次引导作废
- 家具引导：`_cancel_pending_trigger()` 清旧指令；未邻接则设 `_pending_trigger_interaction`，到达后由 `_on_state_changed` 自动触发交互（一次点击完成）
- 防连点：`_attract_seq` 序号校验，新引导会取消旧引导后续的移动
- 吸引物：点击处放置物品并上下漂浮（`_draw_attract_item` 绘制，`_attract_item` 状态）；预置 6 种（`ATTRACT_ITEMS`：爱心/小鱼干/苹果/星星/毛线球/书卷），`general.attract_item` 可固定或 `random`（默认随机），设置界面「通用」页 `AttractOption` 选择；角色到达物品格后 `_on_attract_arrived()` 清除物品；已移除原 `_draw_target` / `_draw_path`（目标十字与路径线）

### P2 自主行为 + 状态系统（初版已实现 2026-08-30）
> 需求定稿见 `doc/产品规划与路线图.md` §7「P2 落地规则」。实现：
> - `scripts/autoload/StatusManager.gd`（新 autoload）：状态持久化 `user://status.json`（饱食/心情/疲惫 + 食物 raw/cooked + 每日自主好感计数 + `last_seen`）；现实时间缓慢变化（饱食 -1/30min、疲惫 +1/30min）；`general.dev_state_speed` 测试倍率（正式版移除）；`try_autonomy_affection` 50% 概率 +1、日上限 3；`apply_offline_seconds` 离线自然变化
> - 行为调度在 `GameMain._autonomy_*`：空闲 ≥8s 且无电脑 OS/全屏浮层开始（手机开着照常）；状态阈值优先（饿了吃/累了睡/心情低落去窗边）→ 随机闲逛 → 三段日程（22–6 倾向休息）；同目标冷却（`_last_autonomy_type`）；玩家输入打断（`_mark_player_activity`）
> - 进食链路：新家具 冰箱 `fridge`（拿食物）/ 厨具 `cook`（做饭，心情+1）/ 饭桌 `eat`（吃：生食 +20 饱食 +3 疲惫；熟食 +35 饱食 +2 心情 +2 疲惫；沙发 `rest` 有食物时也吃）
> - 自主用电脑：`computer_play` 走到电脑旁并显示 `UI/PlayTogetherButton`「一起玩」，点击 `open_panel()+open_game_select()` 直达游戏选择
> - 离线结算：上线时离线 ≥ `1800/dev_speed` 秒 → `apply_offline_seconds` 先算自然变化 → `AIConnector.request_json`（带人设/记忆/状态）输出 `{"satiety","fatigue","mood","affection","message"}` 一次性应用（±范围钳制）；affection 计入自主好感每日上限；失败走时间降级
> - 聊天：`MemoryManager.build_chat_context` 注入好感度描述；手机/电脑判定均支持 `mood_delta`（-2~+3 缺省 +1）并经 `StatusManager.apply_delta` 应用

### 房间布置与帮助
- 家具规格统一在 `GameMain.FURNITURE_SPECS`（id/name/interaction/desc/size/pos/color），布置、绘制、碰撞、帮助说明都从中读取
- 房间布置：`room_layout_overlay.tscn/gd` + `room_layout_grid.gd`；交互 `decorate`（布置台），长按 0.4s 拾起 → 移动 → 点击放下，冲突校验；保存 `user://room_layout.json`，可恢复默认；**该交互不加好感度**
- 帮助浮层：`help_overlay.tscn/gd`；首次进入自动弹新手攻略（`general.guide_seen`），「家具介绍」按钮展示 `FURNITURE_SPECS.desc`

## 如何添加新家具

1. 在 `scripts/GameMain.gd` 的 `FURNITURE_SPECS` 中追加一条：
   ```gdscript
   {"id": "xxx", "name": "显示名", "interaction": "交互名", "desc": "功能说明（家具介绍用）",
    "size": Vector2i(1, 1), "pos": Vector2i(x, y), "color": Color(0.5, 0.5, 0.5)}
   ```
2. 添加对应绘制函数（如 `_draw_xxx()`），并在 `_draw_furniture()` 中调用。
3. 在 `_on_character_interaction()` 中处理需要特殊行为的交互（例如 `computer`）。
4. 家具列表、碰撞、布置界面、家具介绍均自动生效；`desc` 会显示在「家具介绍」中。
