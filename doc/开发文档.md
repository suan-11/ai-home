## 1. 技术栈与项目配置

- 引擎：Godot 4.x（本机 4.7.2），GDScript；渲染 GL Compatibility
- 主场景：`scenes/main.tscn`；仓库：`https://github.com/suan-11/ai-home`
- 基础分辨率 480×360；默认窗口 1280×720 最大化；拉伸 `canvas_items` + `keep`；F11 全屏
- 打包形态：exe + pck 分离 + 外部 `assets/bgm/`（见 `发布与打包.md`）

## 2. 全局单例（project.godot → autoload）

## 3. 主流程与房间

- `scripts/GameMain.gd`（约 1600 行，主流程）：房间绘制、家具规格、点击 / 吸引、布置、帮助、自主行为调度（`_autonomy_*`）、离线结算、手机与浮层接线
- `scenes/main.tscn`：房间 / 角色 / 立绘层 / 侧边栏按钮（设置 / 手机 / 角色）/「一起玩」按钮
- 网格：16×12，单格 16px，原点 `GRID_ORIGIN = (160, 84)`（房间右移后的当前值），角色坐标取格子中心
- 寻路：`scripts/logic/pathfinding.gd`（4 向 A*）；状态机：`scripts/logic/state_machine.gd`（IDLE / WALK_TO）
- 角色控制：`scripts/char/char_controller.gd`（逐格移动、家具碰撞、`trigger_interaction`、`play_action`、`set_character`）

## 4. 家具与交互

- 家具唯一数据源：`GameMain.FURNITURE_SPECS`（id / name / interaction / desc / size / pos / color）——绘制、碰撞、布置、家具介绍都从这里读取；位置可被 `user://room_layout.json` 覆盖
- 当前家具：床 `sleep`、电脑 `computer`、书架 `read`、椅子 `sit`、电视柜 `watch`、沙发 `rest`、落地灯 `light`、盆栽 `water`、布置台 `decorate`、冰箱 `fridge`、厨具 `cook`、饭桌 `eat`
- 点击家具：吸引角色到旁边 → **到达后自动触发交互**（一次点击完成；邻接时直接触发）
- 房间布置：`room_layout_overlay.tscn/gd` + `room_layout_grid.gd`；长按 0.4s 拾起 → 点击放下；不加好感
- 吸引移动（P1）：`GameMain._attract_to_cell` / `_attract_to_furniture`；「！」+ hop → 0.4s → 自愿寻路；响应概率按好感等级（Lv5–6 必应 / Lv3–4 92% / Lv1–2 85%）；走神冒「？」

### 如何添加新家具

1. 在 `GameMain.FURNITURE_SPECS` 追加一条：`{"id","name","interaction","desc","size","pos","color"}`
2. 添加绘制函数（如 `_draw_xxx()`）并在 `_draw_furniture()` 中调用
3. 需要特殊行为时在 `_on_character_interaction()` 处理（参考 `computer`）
4. 家具列表、碰撞、布置界面、家具介绍自动生效

## 5. 自主行为 + 状态（P2）

- 调度：`GameMain._autonomy_*`——空闲 ≥8s 且电脑 OS / 全屏浮层未开时启动；玩家输入立即打断；状态阈值优先 → 随机闲逛 → 三段日程（06–18 活跃 / 18–22 渐缓 / 22–06 倾向休息）；同目标冷却
- 进食链路：冰箱 `fridge` 拿食物 → 直接吃（生食 +20 饱食 / +3 疲惫）或 厨具 `cook` 做饭（心情 +1）→ 饭桌 `eat` 或沙发 `rest` 吃（熟食 +35 饱食 / +2 心情 / +2 疲惫）
- 自主好感：完成正式自主行为 50% 概率 +1，每日上限 +3
- 离线结算：离线 ≥ `1800 / dev_state_speed` 秒 → 先自然变化，再 `AIConnector.request_json` 输出 `{satiety, fatigue, mood, affection, message}` 一次性应用（钳制 0–100），失败降级
- 状态：在线缓慢变化（饱食 -1/30min、疲惫 +1/30min）；测试倍率 `general.dev_state_speed`（×1/×5/×10，正式版建议移除）；纯表现、无数值 UI
- 心情：聊天 / 手机 AI 可返回 `mood_delta`（-2~+3，缺省 +1），经 `StatusManager.apply_delta` 应用

## 6. 电脑 OS 与游戏

- 外壳：`scenes/ui/computer_panel.tscn` + `scripts/ui/computer_panel.gd`；子界面统一在 `Panel/ScreenArea`（约 432×268，clip）内切换，**禁止叠加**；`_screen_stack` 导航栈
- API：`show_desktop` / `open_game_select` / `open_gomoku` / `open_graphwar` / `open_tictactoe` / `open_blackjack` / `open_snake` / `open_settings` / `open_chat` / `open_diary` / `go_back` / `get_current_screen_id`；`Transition` 枚举（FADE / SLIDE_* / SCALE）
- 游戏中心：`scripts/ui/game_select.gd` 的 `GAMES` 注册表（id / name / desc）自动生成滚动卡片；当前 5 款游戏 + 「更多游戏」占位
- 5 款游戏：gomoku（五子棋）/ graphwar（函数对打）/ tictactoe（井字棋）/ blackjack（21点）/ snake（贪吃蛇），均为 `.tscn` + 同名 `.gd`

### 如何新增小游戏（必须接线 4 处）

1. `game_select.gd` 的 `GAMES` 注册表加一行（id / name / desc）
2. `computer_panel.gd`：加 `SCREEN_*` 常量 + `open_xxx()` 函数（preload 场景）
3. `_setup_screen_signals()`：连接 `screen.<game>_requested` → `open_<game>`
4. `go_back()` 的 match 分支加对应退回目标

> 2026-09-04 曾漏接 `snake_requested` 导致按钮无反应，务必逐项检查。
> 胜负统一：胜 +3 / 平 +1 / 负 0，并调用 `MemoryManager.record_daily_event(...)`。

### 如何新增电脑应用

1. 新建 `scenes/ui/xxx_screen.tscn`（根 Control，填满 ScreenArea，使用锚点 + 容器）
2. `computer_panel.gd` 增加 preload + `open_xxx()` + `go_back()` 分支
3. 在桌面 / 游戏中心等入口发出请求信号并接线
4. 新界面遵循底部「返回」协议（`back_requested`）

## 7. 角色系统

- 目录规范：`assets/chars/<char_id>/`，完整字段见 [`../assets/chars/README.md`](../assets/chars/README.md)
- 自动发现：`scripts/logic/character_catalog.gd`（`CharacterCatalog`）扫描 `res://assets/chars/*`
  - 可用判定：`persona.json` + `portrait.png` + `sprites/`（`idle_0.png` 或 `walk_0.png` 之一）
  - 可选降级：`portraits/` 差分立绘（缺失用单张）、`interactions.json` 互动（缺失无菜单）
  - 排序：`persona.json` → `order`（默认 99）
- 切换链路：`GameManager.set_current_char_id()` → `current_char_changed` 信号 → `GameMain._apply_character` → `char_controller.set_character` / `portrait_manager.set_character` / `StatusManager.set_character` / 互动菜单重建
- 数据分区：好感 / 记忆 / 日记 / 状态 / 互动次数均按 char_id 存取；旧存档 current_char_id 不可用时回退到默认角色
- 互动：`scripts/logic/character_interactions.gd`（`CharacterInteractions.load_specs(char_id)`）读取角色 JSON；支持 `entry: character`（点击角色）与 `entry: furniture:<交互名>`（家具触发）
- **默认角色常量**（替换正式角色时同步修改）：`GameManager.DEFAULT_CHAR_ID`、`StatusManager.DEFAULT_CHAR_ID`、`char_controller.DEFAULT_CHAR_ID`（当前均为 `"char_03"`）
- 部分 UI 脚本保留 fallback 常量与默认文案（`chat_screen` / `diary_screen` / `phone_overlay` / `portrait_manager` / `blackjack_game` / `snake_game` / `help_overlay` / `notification_toast`），运行时由 `GameManager.get_current_char_id()` 覆盖——替换角色时见 `正式角色计划.md` 第 5 节清单

## 9. 配置、数据与 AI

### user:// 数据文件

| 文件 | 内容 |
|---|---|
| `user://config.json` | AI 配置、`general.guide_seen`、`general.attract_item`、`general.dev_state_speed`、音频设置 |
| `user://memory.json` | 记忆 / 日记（按 char_id 分区） |
| `user://game.json` | 好感等级 EXP、互动次数、当前角色、每日记录（按 char_id 分区） |
| `user://status.json` | 状态（饱食 / 心情 / 疲惫 / 食物 / 自主好感计数）（按 char_id 分区） |
| `user://room_layout.json` | 家具布局 |

> `user://` = `%APPDATA%\Godot\app_userdata\AIHome`。API Key 明文存 `config.json`，注意不要提交 / 外发。

### AIConnector 要点

- 接口：OpenAI 兼容 `/chat/completions`；`request_json` / `request_text` 带每请求回调
- `_extract_json` 容错：去 Markdown 围栏 + 括号配对提取最外层 JSON；失败打印原文到控制台；提示词使用严格 JSON + 示例
- 错误回调经 `bind` 会先收到 message 参数导致错位，需用 lambda 包装
- `affection` / `mood_delta` 均做多形式归一化（true / 是 / 1 / 对 / 加分等）

## 10. 验证

```bash
# 1) 新增脚本 / 资源后先导入（暴露 Parse Error 等）
"C:/Users/JOYCEPC/Godot/Godot_v4.7.2-stable_win64_console.exe" --headless --import --path .

# 2) 冒烟（先挪开 user://config.json，防止离线结算 / 聊天触发真实 API）
#    %APPDATA%\Godot\app_userdata\AIHome\config.json → config.json.bak
"C:/Users/JOYCEPC/Godot/Godot_v4.7.2-stable_win64_console.exe" --headless --path . --quit-after 150
```

- `--headless --script` 独立模式**不注册 Autoload**（引用 GameManager 会编译错误）；自动化验证要在正常游戏流程（环境变量钩子 / 临时场景）内跑
- GDScript `var x := 表达式` 含动态 / Variant 值时用显式类型或 `var x = ...`，否则报 Cannot infer the type
- 字符串格式化 `%` 优先级高于 `+`：多段拼接需整体加括号 `("A" + "B") % [args]`
- `Array[String]` 没有 `join()`，用 `PackedStringArray` 或手写
