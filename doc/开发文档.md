# 开发文档

## 技术栈

- 引擎：Godot 4.x
- 语言：GDScript
- 渲染：GL Compatibility
- 项目配置：`project.godot`

## 核心模块

### 主场景 `scenes/main.tscn`
- 根节点：`Main`（Node2D）
- 子节点：
  - `Room/Character`：角色
  - `UI/StatusLabel`：状态提示
  - 运行时动态加入 `UI/ComputerPanel`

### 角色控制 `scripts/char/char_controller.gd`
- 网格逐格移动
- A* 寻路（`scripts/logic/pathfinding.gd`）
- 状态机（`scripts/logic/state_machine.gd`）
- 家具碰撞
- 交互触发信号

### 寻路 `scripts/logic/pathfinding.gd`
- 4 方向 A*
- 支持障碍格
- 返回 `Array[Vector2i]` 形式的路径

### 电脑面板与游戏模块
- `scenes/ui/computer_panel.tscn`：电脑四宫格面板
- `scenes/ui/game_select.tscn`：游戏选择界面
- `scenes/ui/gomoku_game.tscn`：标准 15×15 五子棋界面
- `scripts/ui/computer_panel.gd`：面板开关、动画、模块跳转
- `scripts/ui/computer_screen.gd`：仿电脑界面装饰绘制（外框/桌面/标题栏/任务栏）
- `scripts/ui/game_select.gd`：游戏选择与子游戏打开/关闭
- `scripts/ui/gomoku_game.gd`：15×15 棋盘、玩家/AI 落子、胜负判断、AI 启发式评分、结果面板与预留接口

### 配置与 AI
- `ConfigManager`：读写 `data/config.json`（后续实现）
- `MemoryManager`：记忆数据（后续实现）
- `AIConnector`：预留 `send_chat(messages)` 接口

## 如何添加新家具

1. 在 `scripts/GameMain.gd` 的 `_build_blocked_cells()` 中调用：
   ```gdscript
   _add_furniture(
       blocked,              # 碰撞字典
       "家具名",             # 显示名
       "interaction_name",   # 交互接口名
       Vector2i(x, y),       # 左上角格子
       Vector2i(w, h)        # 宽高（格子数）
   )
   ```
2. 添加对应绘制函数，并在 `_draw_furniture()` 中调用。
3. 在 `_on_character_interaction()` 中处理需要特殊行为的交互（例如 `computer`）。

## 坐标系统

- 房间网格：16 × 12
- 单格：16 × 16 像素
- 格子原点：`(112, 84)`
- 角色位置：格子中心

## 窗口与分辨率

- 基础分辨率：480 × 360
- 默认窗口：1280 × 720，启动最大化
- 拉伸模式：`canvas_items`
- 保持比例：`keep`
- 快捷键：F11 切换全屏

## 验证命令

安装 Godot 后，可在项目目录运行：

```bash
godot --headless --path . --quit-after 60
```

用于检查项目是否能无报错加载。
