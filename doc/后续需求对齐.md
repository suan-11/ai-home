## 待与用户确认的需求点

### 1. 聊天模块
- 是否接入真实 AI API？
- 使用哪种接口：OpenAI 兼容 / DeepSeek / Ollama 本地？
- 聊天界面是否做成电脑系统里的一个“应用”？
- 是否需要设置页（Base URL / API Key / 模型列表）？

### 2. 日记 / 好感度
- 日记需要记录哪些内容？（好感度、重要对话、成就、角色状态？）
- 好感度怎么变化？（聊天、游戏胜负、日常互动？）
- 是否需要在电脑系统里做一个“日记应用”？

### 3. 游戏模块
- 下一款小游戏做什么？
- 游戏是否都要“和 AI 对战”？
- 游戏是否影响好感度/奖励？

### 4. 角色与视觉
- 是否保留早期设计的“左侧二次元立绘 + 右侧像素房间”布局？
- 是否做差分表情、视线跟随？
- 角色是否需要多角色切换？

### 5. 早期玩法
- 状态数值（饱食 / 精力 / 心情 / 好奇）是否保留？
- 权重寻路（时间 / 状态 / 用户行为影响走路偏好）是否要做？
- 家具交互触发状态恢复（睡觉/吃东西/休息）？

### 6. 平台与发布
- 目标平台：仅 Windows？还是 Linux / Steam Deck？
- 是否考虑 Web 版？

### 7. 语音与辅助
- TTS / 语音播放是否纳入当前计划？
- 是否需要背景音乐 / 音效？

### 8. 编辑器与扩展
- 房间编辑器（可视化拖拽）是否保留？
- 多房间、Mod 加载新角色是否保留？
