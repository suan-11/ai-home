## 1. 功能方向（大项）

| 方向 | 说明 | 来源 |

| TTS 语音 | 接入 Edge-TTS 等朗读 AI 回复；可扩展口型同步 | 原 P4 / 早期设计 |
| 流式输出 | 聊天 / 手机回复逐字显示，降低等待感 | 交接记录 |

| Mod 支持 | 用户放入 `assets/chars/` 新角色即用（exe+pck 分离 + 外部 assets 已铺路） | 早期设计 / 原 P4 |
| 本地小模型 | 接入 Ollama 等本地 API，离线可用 | 早期设计 |
| 可视化房间编辑器 | 拖拽式编辑，替代当前「长按-点击」简化版 | 早期设计 |
| 多方向行走动画 | 上 / 下 / 左 / 右四向行走帧 | 2026-09-04 用户搁置，保留选项 |

| 更多角色 | 正式角色之外的扩展角色库 | 规划 |
| 平台扩展 | Linux / Steam Deck / Web（待确认） | 需求对齐待定项 |

## 2. 调优清单（需实测反馈）

- **P2 参数**：状态速率 / 阈值 / 概率 / 时长（集中在 `GameMain` 顶部常量与 `StatusManager`）
- **互动数值**：5 条互动的效果 / 频率 / 冷却微调；投喂库存系统
- **Graphwar**：AI 难度档、障碍数量与血量、瞄准偏移量
- **吸引移动**：更多反应动画、走神种类、响应概率微调
- **UI**：对比度 / 间距 / 手感（480×360 与全屏）；批次 2 的 `data/games.json`（可选，当前脚本常量表已够用）
- **立绘**：备用档 `angry` / `blushing_worried` 接入

## 4. 技术债 / 已知约束

- API Key 明文存 `user://config.json`（仅本地）
- 无 API 时：聊天 / 手机 AI 回复、离线结算、日记 AI 整理自动降级
- 部分旧界面仍保留手写绝对坐标（新界面请用「锚点 + 容器」）
- 旧存档 `current_char_id` 回退逻辑：删除 `char_03` 后老玩家会回退到默认角色（替换时需实测）
- 外部 `.flac` 播放未实测（`AudioStreamWAV.load_from_file` 对 flac 的支持待确认；不行则限制为 wav/ogg/mp3）
- `user://` 数据与运行器独立；发布包内数据目录为 `%APPDATA%\Godot\app_userdata\AIHome`

## 5. 历史 / 已废弃方案（勿重复提案）

- 权重寻路 / 状态数值细分：用户答「以后再说」（2026-08-29）
- 状态数值 UI：后置设计，目前纯表现
- 房间编辑器拖拽版：以「布置台」长按-点击简化版先行替代
