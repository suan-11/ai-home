# AIHome / AI-Character-home

一个使用 **Godot 4.x / GDScript** 制作的 2D 像素风 **AI 陪伴**项目：让一个 AI 生活在这个房间里，你像养宠物的主人一样与它相处——它有自己的生活（自主闲逛、自己用家具、按作息活动），也会回应你的吸引、陪你玩小游戏、和你发消息。

**核心体验：自主 + 可被影响。** 它是会自己生活的"室友/宠物"，而你的吸引、陪伴和互动能引导它的行为。

当前阶段：可运行的温馨小屋原型（网格寻路、家具交互、仿电脑操作系统、游戏选择、AI 五子棋、聊天/日记、房间布置、新手攻略），并已确定后续「手机消息、自主行为、内部状态」等功能规划。

> 文档以项目实际实现和用户确认为准；`doc/aihome描述.md`、`doc/aihome具体.md` 是早期设计稿，部分内容尚未实施或可能调整。产品方向与功能规划以 [`doc/产品规划与路线图.md`](doc/产品规划与路线图.md) 为准。

## 运行方式

1. 安装 [Godot](https://godotengine.org/download) 4.3+（推荐 4.7+）
2. 用 Godot 打开本项目根目录的 `project.godot`
3. 按 **F5** 运行

## 操作

| 操作 | 效果 |
|---|---|
| 鼠标左键点击地板 | 角色 A* 寻路走到目标格子 |
| 点击家具 | 已在旁边则触发交互；否则走到旁边空位 |
| 点击电脑 | 打开仿电脑操作系统（桌面/应用界面） |
| 点击「布置台」 | 弹出房间布置界面：长按家具拾起→移动→点击放下；可保存/恢复默认 |
| 首次进入游戏 | 自动弹出新手攻略；关闭后不再自动弹出 |
| 右侧「家具介绍」 | 查看每件家具的功能说明 |
| 电脑内点击 游戏/聊天/日记 | 打开对应模块；游戏为选择界面，内含五子棋；日记按日期自动整理 |
| 主界面右上角「设置」 | 打开设置界面（通用/显示/音频/AI 设置） |
| AI 设置中保存 API 信息 | 写入 `user://config.json`，供聊天功能使用 |
| F11 | 切换全屏 |

## 当前功能

- 温馨配色房间：墙体、木地板、窗户、地毯
- 左侧角色立绘叠加层（当前角色：梅尔 char_03，居左显示，不移动房间）
- 家具：
  - 床 `sleep`
  - 电脑 `computer`
  - 书架 `read`
  - 椅子 `sit`
  - 电视柜 `watch`
  - 沙发 `rest`
  - 落地灯 `light`
  - 盆栽 `water`
  - 布置台 `decorate`（摆设界面：自定义家具位置）
- 家具布局自定义：长按拾取/点击放下，保存到 `user://room_layout.json`，可一键恢复默认
- 新手攻略：首次进入自动弹出（操作说明），关闭后不再弹；右侧「家具介绍」可随时查看家具功能
- 网格 A* 寻路
- 家具碰撞和“先走到旁边再交互”的交互系统
- 仿电脑操作系统（显示器外框/标题栏/任务栏/桌面 + 屏幕切换动画 API）：
  - 游戏（游戏选择界面 + AI 五子棋）
  - 聊天（聊天界面，已接入 OpenAI 兼容接口 + 记忆持久化 + 好感度判定）
  - 日记（按日期自动整理当天聊天/互动/好感度变化；好感度 0-100 持久化）
  - 设置（主界面右上角入口，标签页设置界面）
  - 右下角空位
- 全屏切换与窗口自适应

```
├── scenes/
│   ├── main.tscn           # 主场景
│   └── ui/
│       ├── computer_panel.tscn    # 电脑 OS 外壳（ScreenArea 导航）
│       ├── desktop_screen.tscn    # 桌面应用入口
│       ├── game_select.tscn       # 游戏选择
│       ├── gomoku_game.tscn       # 五子棋
│       ├── chat_screen.tscn       # 聊天应用
│       ├── diary_screen.tscn      # 日记应用
│       ├── help_overlay.tscn      # 新手攻略 / 家具介绍
│       ├── room_layout_overlay.tscn  # 房间布置界面
│       └── main_settings_overlay.tscn # 主界面设置浮层
├── scripts/
│   ├── GameMain.gd                # 主场景：房间/家具/布置/帮助
│   ├── autoload/           # 全局单例：Game/Config/Memory/AI
│   ├── char/               # 角色控制
│   ├── logic/              # 寻路/状态机/行为
│   └── ui/                 # UI 脚本（OS外壳、桌面、游戏、五子棋、聊天、日记、帮助、布置）
├── data/                   # 配置与运行数据
├── setting/                # 地图/权重配置
├── doc/                    # 设计文档（产品规划与路线图、开发文档、需求对齐等）
└── README.md
```
