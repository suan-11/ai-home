# AIHome / AI-Character-home

一个使用 **Godot 4.x / GDScript** 制作的 2D 像素风 **AI 陪伴**项目：让一个 AI 生活在这个房间里，你像养宠物的主人一样与它相处——它有自己的生活（自主闲逛、自己用家具、按作息活动），也会回应你的吸引、陪你玩小游戏、和你发消息。

**核心体验：自主 + 可被影响。** 它是会自己生活的"室友/宠物"，而你的吸引、陪伴和互动能引导它的行为。

当前阶段：可运行的温馨小屋原型（网格寻路、家具交互、仿电脑操作系统、游戏选择（五子棋 / Graphwar 函数对打 / 井字棋 / 21点）、聊天/日记、房间布置、新手攻略、P0 手机消息、P1 吸引移动、P2 自主行为+状态系统、P3 扩展全部实现：Graphwar 函数对打 + 井字棋 + 立绘差分 6 档 + 其他互动（角色文件数据驱动））；P4 已启动——**多角色切换 ✅ + 21点 ✅ 已实现**（梅尔 / 小灯〔临时占位，后续替换〕，主界面「角色」图标切换；21点与 AI 对战），贪吃蛇、多方向行走动画、BGM/TTS 等继续排期。

> 文档以项目实际实现和用户确认为准；`doc/aihome描述.md`、`doc/aihome具体.md` 是早期设计稿，部分内容尚未实施或可能调整。产品方向与功能规划以 [`doc/产品规划与路线图.md`](doc/产品规划与路线图.md) 为准。

## 运行方式

1. 安装 [Godot](https://godotengine.org/download) 4.3+（推荐 4.7+）
2. 用 Godot 打开本项目根目录的 `project.godot`
3. 按 **F5** 运行

## 操作

| 操作 | 效果 |
|---|---|
| 鼠标左键点击地板 | 点击处出现吸引物（随机/设置可固定），当前角色被吸引过去，到达后物品消失；好感度低时偶尔走神冒「？」 |
| 点击家具 | 家具旁出现吸引物并吸引梅尔，到达后自动触发交互 |
| 点击角色 | 弹出互动菜单：摸摸头 / 投喂零食 / 玩小玩具（台词、动作、效果、上限由角色文件 `interactions.json` 定义） |
| 点击冰箱 / 厨具 / 饭桌 | 拿食物 / 做饭 / 吃饭：生食 +20 饱食，熟食 +35 饱食 +2 心情；饭桌或沙发都能吃（无食物时先到冰箱拿） |
| 梅尔自主用电脑时 | 电脑旁出现「一起玩」按钮，点击直接进入游戏选择 |
| 点击电脑 | 打开仿电脑操作系统（桌面/应用界面） |
| 点击「布置台」 | 弹出房间布置界面：长按家具拾起→移动→点击放下；可保存/恢复默认 |
| 首次进入游戏 | 自动弹出新手攻略；关闭后不再自动弹出 |
| 右侧「家具介绍」 | 查看每件家具的功能说明 |
| 电脑内点击 游戏/聊天/日记 | 打开对应模块；游戏为选择界面，内含五子棋、Graphwar 函数对打、井字棋、21点；日记按日期自动整理 |
| 主界面右上角「设置」 | 打开设置界面（通用/显示/音频/AI 设置） |
| 「设置」下方「手机」图标 | 打开半透明手机聊天窗：随时发消息，AI 回复时角色会冒气泡 + 提示音 + 动作动画，结构化指令可吸引角色走向家具 |
| 「手机」下方「角色」图标 | 打开角色选择列表（立绘/名字/性格/好感度），点击即**原地切换**当前陪伴角色；各角色好感度/记忆/日记/状态完全独立 |
| AI 设置中保存 API 信息 | 写入 `user://config.json`，供聊天功能使用 |
| F11 | 切换全屏 |

## 当前功能

- 温馨配色房间：墙体、木地板、窗户、地毯
- 左侧角色立绘叠加层（当前角色随切换变化，居左显示，不移动房间）
- 多角色切换（P4）：主界面「角色」图标打开选择列表（立绘/名字/性格/好感度），点击即原地切换当前陪伴角色；可用角色=目录具备基础素材（`persona.json` + `sprites/` + `portrait.png`），差分立绘/互动为可选（缺失降级显示）；各角色好感度/记忆/日记/状态完全独立；已接入梅尔（完整）与小灯（降级显示；**小灯为临时占位角色，后续替换为正式角色**）
- 家具：
  - 床 `sleep`
  - 电脑 `computer`
  - 书架 `read`
  - 椅子 `sit`
  - 电视柜 `watch`
  - 沙发 `rest`
  - 落地灯 `light`
  - 盆栽 `water`
  - 布置台 `decorate`（摆设界面：自定义家具位置）
  - 冰箱 `fridge`（拿食物）、厨具 `cook`（做饭）、饭桌 `eat`（吃饭；沙发上也能吃）
- 自主行为 + 状态系统（P2 初版）：空闲 8 秒后梅尔自主闲逛/用家具/吃饭/休息/玩电脑；状态（饱食/心情/疲惫 0-100）驱动行为（饿了找吃的、累了去休息，纯表现无数值 UI）；现实时间缓慢变化；离线 ≥30 分钟上线时按现实时间模拟 + AI 结算（含想念留言与情绪变化）；聊天上下文注入好感度与心情变化；自主行为 50% 概率 +1 好感（每日上限 +3）
- 测试设置：通用页「状态变化速度 ×1/×5/×10」（测试用，正式版移除）
- 家具布局自定义：长按拾取/点击放下，保存到 `user://room_layout.json`，可一键恢复默认
- 新手攻略：首次进入自动弹出（操作说明），关闭后不再弹；右侧「家具介绍」可随时查看家具功能
- 网格 A* 寻路
- 吸引移动（P1）：点击地板/家具 = 引导而非命令——点击处放置吸引物（爱心/小鱼干/苹果/星星/毛线球/书卷，通用设置可固定或随机），角色停顿、「！」特效 + 小跳后自愿寻路，到达后物品消失；好感度影响响应概率（≥70 必应 / ≥50 90% / 其余 75%），走神时冒「？」；点击家具到达后自动触发交互
- 家具碰撞和“先走到旁边再交互”的交互系统
- 仿电脑操作系统（显示器外框/标题栏/任务栏/桌面 + 屏幕切换动画 API）：
  - 游戏（游戏选择界面（可滚动列表：五子棋 / Graphwar 函数对打 / 井字棋 / 21点））
  - 聊天（聊天界面，已接入 OpenAI 兼容接口 + 记忆持久化 + 好感度判定）
  - 日记（按日期自动整理当天聊天/互动/好感度变化；好感度 0-100 持久化）
  - 设置（主界面右上角入口，标签页设置界面）
  - 右下角空位
- 手机消息（P0）：手机图标入口 + 半透明竖屏聊天窗（单页、随时可聊）；发消息后角色延迟收到：提示音 + 头顶「！」特效 + 顶部通知横幅，随后 AI 回复（气泡 + 简单动作动画）；发送状态提示在手机右上角逐条队列显示（丝滑滑入/淡出）；AI 结构化指令可让角色走向家具（或 wave/hop/sad）；与电脑纯聊并存，消息同样计入记忆/日记/好感度
- Graphwar 函数对打（P3）：双方各 3 个球（你左侧蓝菱形 / AI 右侧红圆），每回合点选自己一个剩余球、直接输入函数 f(x) 发射——炮弹从该球出发，沿「y = 该球高度 + f(x) − f(0)」飞行，轨迹随炮弹逐步显示；**命中球后炮弹不消失、可连穿多个球，碰到屏幕边缘或球形障碍才消失**；先击毁对方全部 3 球获胜；坐标范围 ±50×±25；支持 + - * / ^ ( )、数字、x、pi、sin/cos/tan/abs/sqrt/ln/exp，乘号可省略；界面内附「教程」（黑底可滚动）；AI 瞄准带随机偏移；胜负沿用好感度规则
- 井字棋（P3）：与 AI 对战（你 X / AI O，3×3 先三连者胜）；AI 会堵你也会自己赢；胜 +3 / 平 +1 / 负 0
- 21点（P4）：与 AI（当前角色=庄家）对战；标准规则（A=1/11 自动适应、J/Q/K=10、超过 21 爆牌；你停牌后 AI 翻暗牌补到 ≥17）；天然黑杰克自动开牌；胜 +3 / 平 +1 / 负 0，记录日常事件 blackjack
- 其他互动（P3，数据驱动）：点击角色弹出互动菜单（摸摸头/投喂零食/玩小玩具）；书架=一起看书、盆栽=浇花；台词/动作/表情/状态效果/好感/每日上限全部由角色文件 `assets/chars/<角色>/interactions.json` 定义，换角色只需改文件
- 立绘差分（P3）：左侧立绘按状态/事件切换 6 档（默认微笑 / 开心 / 低落 / 害羞 / 走神 / 惊讶）——心情 ≥80 开心、心情<30 或饱食<30 低落；收到消息惊讶、被吸引走神、聊天情绪（开心/害羞/难过）、看完电视或书后短暂开心；另有生气/脸红担心 2 张备用档
- 全屏切换与窗口自适应

```
└── README.md
```
