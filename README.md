# AIHome / AI-Character-home

一个使用 **Godot 4.x / GDScript** 制作的 2D 像素风 **AI 陪伴**小游戏：让 AI 住在像素房间里，你像养宠物的主人一样与它相处——它有自己的生活（闲逛、用家具、按作息活动），也会回应你的吸引、陪你玩小游戏、和你发消息。

**核心体验：自主 + 可被影响。** 它是会自己生活的「室友 / 宠物」，你的吸引、陪伴和互动能引导它的行为。

> **当前版本：v0.1.0（首个正式版，2026-09-05 发布）**
>
> - 下载与发布说明：[GitHub Releases](https://github.com/suan-11/ai-home/releases)→ `AIHome-win64.zip`（解压即玩）
> - ⚠️ 当前内置角色「梅尔」使用的**不是本项目原创素材**（来自外部作品），仅作开发与预览用途；下一版本将替换为**原创正式角色**，计划见 [`doc/正式角色计划.md`](doc/正式角色计划.md)

## 运行方式

**玩家（推荐）**

1. 从 [GitHub Releases](https://github.com/suan-11/ai-home/releases) 下载 `AIHome-win64.zip`
2. 解压后双击 `AIHome.exe`
3. 想使用 AI 聊天 / 手机消息 / 日记整理：打开 设置 → AI 设置，填入 OpenAI 兼容接口（Base URL / API Key / 模型）；不填也能玩小游戏与房间互动

**开发者**

1. 安装 [Godot](https://godotengine.org/download) 4.3+（推荐 4.7+）
2. 用 Godot 打开项目根目录的 `project.godot`
3. 按 **F5** 运行（详细架构与验证见 [`doc/开发文档.md`](doc/开发文档.md)）

## 操作

| 操作 | 效果 |
|---|---|
| 左键点击地板 | 点击处出现吸引物，当前角色被吸引过去；到达后物品消失（好感等级低时偶尔走神） |
| 点击家具 | 吸引角色到家具旁，到达后自动触发交互（一次点击完成） |
| 点击角色 | 弹出互动菜单：摸摸头 / 投喂零食 / 玩小玩具（台词、动作、效果、上限由角色文件定义） |
| 冰箱 / 厨具 / 饭桌 | 拿食物 / 做饭 / 吃饭（沙发也能吃；无食物时先去冰箱拿） |
| 点击电脑 | 打开仿电脑操作系统（桌面 → 游戏 / 聊天 / 日记） |
| 点击「布置台」 | 打开房间布置：长按家具拾起 → 移动 → 点击放下；可保存 / 恢复默认 |
| 右上角「设置 / 手机 / 角色」图标 | 设置面板 / 半透明手机聊天窗 / 角色切换列表 |
| F11 | 切换全屏 |

> 电脑 OS 或全屏浮层打开时不能开手机；小游戏共 5 款（五子棋 / Graphwar 函数对打 / 井字棋 / 21点 / 贪吃蛇），均与 AI 对战，胜 +3 / 平 +1 / 负 0 好感。

## 当前功能（v0.1.0）

- **房间**：16×12 像素房间、网格 A* 寻路、家具碰撞、房间布置（自定义家具位置并保存，可恢复默认）
- **吸引移动（P1）**：点击 = 引导而非命令；6 种吸引物（设置可固定 / 随机）；角色「！」+ 小跳反应后自愿寻路；好感等级影响响应概率，走神时冒「？」
- **自主生活 + 状态（P2）**：闲逛 / 自主用家具 / 三段日程（按现实钟点）/ 进食链路（冰箱 → 厨具 → 饭桌）；饱食 / 心情 / 疲惫驱动行为（无数值 UI）；离线 ≥30 分钟上线有 AI 结算与「想念」留言
- **电脑 OS**：桌面 / 游戏中心（滚动卡片）/ 聊天 / 日记 / 设置；5 款小游戏与 AI 对战
- **手机消息（P0）**：半透明竖屏聊天窗；提示音 + 头顶「！」+ 顶部横幅 + 气泡 + 动作动画；AI 结构化指令可让角色走向家具（或 wave / hop / sad）
- **好感等级**：Lv1 朋友 → Lv6 家人（EXP 累积）；升级有横幅 / 台词 / 立绘反馈；各角色数据独立
- **角色互动（P3）**：摸摸头 / 投喂零食 / 玩小玩具 / 一起看书 / 浇花；台词、动作、表情、效果、好感、上限全部由 `assets/chars/<角色>/interactions.json` 数据驱动
- **立绘差分（P3）**：默认 / 开心 / 低落 / 害羞 / 走神 / 惊讶 6 档（状态阈值 + 事件触发）
- **多角色切换（P4）**：角色目录自动发现；主界面「角色」图标原地切换；每人好感 / 记忆 / 日记 / 状态独立；缺差分立绘 / 互动自动降级
- **记忆与日记**：短期记忆 40 条 + 长期摘要 + key_facts；日记按日期自动整理（有 API 走 AI，失败降级）
- **UI**：方案 A「暖屋手账」全局主题（奶白纸面 + 木纹 + 暖金 + 蜜桃橙）
- **BGM（P4）**：在游戏目录 `assets/bgm/` 放置自备音频（`.wav/.ogg/.mp3/.flac`）循环播放；空则不播放；设置「音频」页音量 / 静音即时生效
- **其他**：新手攻略 / 家具介绍、F11 全屏、窗口自适应

> ⚠️ 「梅尔」为外部作品素材（非原创），开发 / 预览用；「小灯」为临时占位（基础素材）。原创角色制作见 [`doc/正式角色计划.md`](doc/正式角色计划.md)。

### 小游戏一览（均与 AI 对战，胜 +3 / 平 +1 / 负 0）

| 游戏 | 玩法摘要 |
|---|---|
| 五子棋 | 15×15 标准规则 |
| Graphwar 函数对打 | 双方各 3 球；直接输入 f(x) 发射，炮弹可连穿多球；先击毁对方全部球获胜 |
| 井字棋 | 3×3，先三连者胜（AI 非完美，玩家可赢） |
| 21点 | AI 当庄家；标准规则，玩家停牌后庄家补到 ≥17 |
| 贪吃蛇 | 24×15 场地，先吃满 8 分获胜；撞墙 / 撞蛇判负 |

## 目录结构

```
ai-home/
 project.godot
 assets/
    chars/              # 角色资源（规范见 assets/chars/README.md；char_02 为正式角色预留）
    ui/                 # 图标（设置 / 手机 / 角色）
    bgm/                # 用户自备背景音乐（空则不播放）
    sfx/                # 音效（手机消息提示音）
 scenes/                 # 主场景 + UI 场景（电脑 OS / 5 款小游戏 / 手机 / 聊天 / 日记等）
 scripts/
    GameMain.gd         # 主流程：房间 / 家具 / 布置 / 吸引 / 自主行为
    autoload/           # GameManager / ConfigManager / MemoryManager / AIConnector / StatusManager / AudioManager
    char/               # 角色控制
    logic/              # 寻路 / 状态机 / 角色目录
    ui/                 # UI 脚本
 tools/                  # 辅助工具（示例 BGM 生成器等）
 doc/                    # 文档（见下方导航；历史文档在 doc/archive/）
 README.md
```

## 数据位置

游戏数据保存在 `%APPDATA%\Godot\app_userdata\AIHome`（`user://`）：设置 / 记忆 / 好感 / 状态 / 房间布局。API Key 只保存在本地，不会提交到仓库。
