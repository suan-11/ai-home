# BGM 文件夹

把想作为**房间背景音乐**的音频文件放进本文件夹即可（无需改代码、无需改设置）：

- 支持格式：`.wav` / `.ogg` / `.mp3` / `.flac`
- 支持**多个文件**：按文件名排序后循环轮播（播放完最后一首回到第一首）
- 文件夹为空 → **不播放**（静音由「设置 → 音频」控制）
- 重启游戏后新文件会被扫描到（Godot 导入新资源后生效）

示例（可选）：仓库附带 `tools/gen_bgm.py`，运行后会在本文件夹生成一段 16 秒的暖色像素风 BGM 示例：
`python tools/gen_bgm.py`

> 注意：正式发布时建议这里只放你授权的 BGM 文件。
